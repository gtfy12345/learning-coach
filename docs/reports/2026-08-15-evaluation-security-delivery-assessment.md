## 2 会话中的主要阻点/痛点

### 2.1 评估器空列表回退缺陷被测试抓住

- **证据**：`evaluate_retrieval([])` 原以 `cases or EVALUATION_CASES` 兜底，空列表被当作未传参而跑全集；测试断言暴露后改为显式 `is None` 判断。
- **影响**：一次即时修复；说明"空输入"用例对可选参数函数必要。

### 2.2 PII/注入样例与规则的边界摩擦

- **证据**：中文角色覆盖样例第一版不匹配窄规则；超长文本截断使尾部注入不可见（符合 5 万字符扫描上限设计）；身份证/卡号正则的数字边界在连续数字串中不误报。
- **影响**：样例按规则收敛而非放宽规则；截断行为作为设计特性写入测试。

### 2.3 注入加固触及教学提示词

- **证据**：`_format_study_context` 包定界符与加固声明是本阶段唯一的行为增强；fake 模型测试不受影响，真实提示词变化通过单元断言锁定。
- **影响**：低风险落地；已在 README 声明其为纵深防御一层而非免疫。
