## 2 会话中的主要阻点/痛点

- 空配置首次启动路径一度不可用。
  - **证据**：首次浏览器验收时 `GET /api/model-config` 返回 503，配置测试方法也会先初始化环境模型。
  - **影响**：没有 `.env` 的用户虽然能打开设置页，却不能从页面完成首次配置，与产品目标直接冲突。
- 新运行时与旧首页配置投影一度不同步。
  - **证据**：设置页应用候选后，`GET /api/config` 仍尝试读取环境模型并报告未配置；新增跨页面回归后复现并修复。
  - **影响**：设置页显示应用成功，首页却继续禁用开始按钮，形成相互矛盾的产品状态。
- 文档索引检查仍报告仓库既有的 10 个 orphan 与 4 个缺失链接警告。
  - **证据**：`sync-doc-index.py --check` 返回 0 violations / 0 drifts，同时列出既有 dangling 项。
  - **影响**：不阻断本次交付，但降低全仓文档检查信噪比。
