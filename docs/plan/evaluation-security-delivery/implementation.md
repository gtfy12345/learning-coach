# 评价、安全与完整交付实施计划

> **版本**: 1.0
> **状态**: completed
> **更新日期**: 2026-08-15

**关联 Checklist**: [implementation-checklist.md](./implementation-checklist.md)

## 1 目标

为学习闭环补齐确定性评价（RAG 评估集与指标、轨迹不变量、掌握图谱）与应用内安全（PII 标记、Prompt 注入防护、可观测性汇总），并以阶段报告作为收官交付成果；保持既有流程、阈值与协议不变。

## 2 背景

前十一个阶段让闭环能诊断、检索、讲解、练习、评价、补救、并行、编排、记忆与时间旅行，但系统缺少对自身的度量：检索质量没有可重复的评估集，多 Agent 轨迹只有展示轨迹没有不变量检查，学习结果只有分数没有概念级图谱；同时资料与回答中的 PII 和注入指令没有任何检测。收官阶段补齐这两块并输出统一阶段报告。

## 3 实施步骤

### Phase 1: 安全层
#### 1.1 实现 PII 与注入检测、脱敏与报告
#### 1.2 教学资料上下文定界与加固声明
#### 1.3 收集节点与 Web 输入的安全轨迹接入

### Phase 2: 评价层
#### 2.1 定义评估集与检索评价（hit@3 / MRR）
#### 2.2 实现轨迹不变量评价
#### 2.3 实现掌握图谱与遥测汇总

### Phase 3: 阶段报告与集成
#### 3.1 实现 build_stage_report 节点并接入图
#### 3.2 CLI evaluate 子命令与会话报告输出
#### 3.3 Web 结果视图展示阶段报告

### Phase 4: 公开文档、完整验证与公众号文章
#### 4.1 更新 README 与边界
#### 4.2 全量回归、文档生命周期同步与交付复盘
#### 4.3 生成并检查第 12 篇公众号文章

## 4 验收标准

- 评估集可经 CLI 运行，指标可重复且与测试一致。
- PII/注入样例被标记且报告不含原文；流程不被阻断。
- 资料上下文带定界与加固声明。
- 完成会话输出包含掌握图谱、轨迹检查、安全摘要与遥测的阶段报告。
- 全量测试通过；第 12 篇文章与实现一致并包含仓库地址。

## 5 风险与应对

| 风险 | 应对措施 |
|------|----------|
| 评估指标随 hash 嵌入波动 | 阈值取实测基线并留缓冲，评估集固定文本 |
| 注入规则误报 | 只标记不阻断，规则窄集合并文档化为启发式 |
| 掌握图谱概念缺失 | 主题与缺口词回退，字段全部可选 |
| 报告泄露敏感内容 | 白名单字段 + 无原文 + 测试断言 |
| 新节点拖慢会话 | 报告构建为纯内存聚合，无 IO |
