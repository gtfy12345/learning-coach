# GraphRAG 与知识前置图实施计划

> **版本**: 1.0
> **状态**: completed
> **更新日期**: 2026-08-15

**关联 Checklist**: [implementation-checklist.md](./implementation-checklist.md)

## 1 目标

在已有多模态资料摄取和自校正 Hybrid RAG 之上，实现离线默认、模型可注入的概念图构建、实体消歧、有界前置图遍历、图与 Hybrid 排名融合，并把“为什么需要补某个前置知识”接入教学 Prompt、LangGraph State、SSE 与 Web。

## 2 背景

第 06 阶段能够找到相关 Chunk 并在证据不足时再次检索，但仍以片段相似性为主。教学中的前置关系通常跨片段表达，例如“条件路由依赖结构化 State，而并行 State 更新又依赖 Reducer”。本阶段需要把这些关系组织成可追溯概念图，使系统不仅找到资料，还能解释补课顺序。

## 3 实施步骤

### Phase 1: 图 Schema、实体关系抽取与消歧

#### 1.1 定义概念图、关系、路径和 GraphRAG 报告 Schema

增加稳定、可序列化且有资源上限的数据契约，新字段全部可选以保持兼容。

#### 1.2 实现确定性实体与关系抽取器

覆盖中英文前置句式、组成/关联关系、标题和代码标识符，保留证据 Chunk。

#### 1.3 实现实体规范化、别名消歧与可注入模型增强

合并显式别名和高置信变体；不确定同名保持独立；模型输出必须结构化校验且可安全降级。

### Phase 2: 概念图构建与有界前置遍历

#### 2.1 构建稳定、去重、有界的会话级概念图

限制 Chunk、字符、节点和关系数量，拒绝自环并稳定生成 ID 和顺序。

#### 2.2 实现查询种子识别与多级图遍历

从主题、诊断重点、知识缺口、最近错误和 Hybrid 命中中选种子，执行深度、节点和路径均有上限的 BFS。

#### 2.3 生成前置知识解释与证据链

把目标、前置路径、当前缺口匹配和来源位置组合为有边界、非臆测的教学理由。

### Phase 3: 图与 Hybrid RAG 融合

#### 3.1 实现图证据排名和图/Hybrid RRF

按距离、关系置信度和上下文匹配得到图排名，再与 Hybrid 排名融合并记录分数。

#### 3.2 实现 GraphStudyRetriever 与安全降级

包装现有 Hybrid Retriever；无图、抽取异常或模型增强失败时保持原 Hybrid 结果。

#### 3.3 接入兼容检索适配器和公共工厂

让结构化 Chunk 与旧粘贴文本都使用 GraphRAG，保留 `retrieve_study_sources` 返回契约。

### Phase 4: LCEL、Middleware、State 与 Web 集成

#### 4.1 把前置路径加入 LCEL 与 Agent 教学上下文

让两条教学模式共享同一 Retriever、最终来源、图报告和补课理由。

#### 4.2 接入 LangGraph State、事件和 Web API

图报告写入可恢复状态，SSE 发送独立图事件，会话视图返回安全图谱投影。

#### 4.3 实现 Web 概念图与前置解释展示

使用原生 HTML/CSS/JS 展示节点、关系、路径和证据位置，无图时隐藏区域并保留原页面流程。

### Phase 5: 文档、完整验证与公众号文章

#### 5.1 更新 README 与公开能力边界

说明默认离线抽取、模型增强 opt-in、融合流程、资源上限、隐私和降级行为。

#### 5.2 完成完整回归、静态验证、生命周期同步与复盘

运行完整测试和静态检查，确认 Header/INDEX 无漂移并生成基于证据的交付复盘。

#### 5.3 生成并视觉检查第 07 篇公众号文章

在 `person` 目录生成 Word 文章，包含 GitHub 地址、实体关系抽取、消歧、图遍历、融合、前置解释、边界和下一阶段，并逐页渲染检查。

## 4 验收标准

- 默认无 API Key 可生成概念图，模型增强只有显式注入才调用。
- 实体、关系、别名、图 ID 和遍历结果确定、可测试且来源可追溯。
- 图遍历覆盖多级、分支、环和无路径场景，并始终在硬上限内终止。
- 图证据与 Hybrid 结果完成排名融合；无图时不改变已有来源结果。
- 教学内容能说明前置路径及其与当前薄弱点的关系，不伪造掌握判断。
- LCEL、Agent、State、SSE、Web 使用同一图报告，旧 API 和旧文本资料兼容。
- 完整测试通过，第 07 篇文章与最终实现一致且包含公开 GitHub 地址。

## 5 风险与应对

| 风险 | 应对措施 |
|------|----------|
| 规则抽取遗漏隐含关系 | 默认聚焦可证实句式，同时提供显式可注入结构化模型增强 |
| 实体误合并 | 只合并显式别名、规范化等价和高置信上下文；不确定时宁可分开 |
| 图循环或资料过大 | Chunk、字符、节点、关系、深度、访问节点和路径均设硬上限 |
| 图分数与向量分数不可比 | 使用 RRF 融合排名，不混合原始分数量纲 |
| 图解释被误读为掌握诊断 | 理由只陈述资料依赖路径和当前错误匹配，不声称已测得掌握关系 |
| State 与前端载荷膨胀 | 只保存安全有界投影，不保存向量和未选中全文 |
| 图模块故障影响教学 | 任何图增强异常都降级为已有 Hybrid RAG |
