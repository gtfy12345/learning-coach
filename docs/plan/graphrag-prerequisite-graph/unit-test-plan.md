# GraphRAG 与知识前置图单元测试计划

> **版本**: 1.0
> **状态**: active
> **更新日期**: 2026-08-15

**关联 Checklist**: [unit-test-plan-checklist.md](./unit-test-plan-checklist.md)

## 1 测试目标

验证实体关系抽取、别名消歧、图构建、有界遍历、前置解释、图与 Hybrid 排名融合以及 LCEL、Middleware、LangGraph 和 Web 集成。所有模型增强测试使用 fake Runnable，不访问网络或真实模型。

## 2 测试策略

- 使用小型中英文 Chunk 验证前置、组成和关联句式，以及标题、缩写和代码标识符。
- 使用同名、大小写、连字符、下划线和显式“全称（缩写）”样本验证消歧边界。
- 使用链、分支、环、自环和超限图验证稳定 ID、去重、遍历终止与排序。
- 使用固定 Hybrid 候选和图候选验证 RRF、最终 top_k、分数投影与无图完全降级。
- 使用 fake Chat Model 验证 Prompt、State、事件、API 和前端安全展示。

## 3 分阶段测试

### Phase 1: Schema、抽取与消歧测试

#### 1.1 Schema

覆盖字段约束、列表上限、分数范围、关系方向、自环拒绝和旧模型兼容。

#### 1.2 确定性抽取

覆盖中英文前置句式、组成/关联、Markdown 标题、代码标识符、无关系文本和稳定顺序。

#### 1.3 消歧与模型增强

覆盖大小写/标点/标识符变体、显式缩写、同名隔离、合法模型输出、非法输出和异常降级。

### Phase 2: 图构建、遍历与解释测试

#### 2.1 图构建

覆盖实体与关系去重、证据合并、稳定哈希、输入截断和节点/边上限。

#### 2.2 图遍历

覆盖单级、多级、分支、环、无路径、深度上限、访问上限和稳定 tie-break。

#### 2.3 前置解释

覆盖当前缺口命中、最近错误命中、仅资料路径、证据位置和无依据不生成。

### Phase 3: GraphRAG 融合测试

#### 3.1 图排名与 RRF

覆盖图距离、置信度、上下文重合、单路/双路、重复候选和 top_k。

#### 3.2 Retriever 降级

覆盖正常增强、空图、抽取异常、无匹配种子、Hybrid 空结果和模型增强失败。

#### 3.3 兼容适配器

覆盖结构化 Chunk、旧粘贴文本、列表接口、报告接口和工厂默认值。

### Phase 4: 教学与 Web 集成测试

#### 4.1 LCEL 与 Middleware

覆盖前置解释进入 Prompt、Agent 工具、Fallback、流式结果与共享 Retriever。

#### 4.2 State、SSE 与 API

覆盖图报告写回、图事件顺序、暂停恢复、JSON 序列化和安全字段。

#### 4.3 Web 展示

覆盖节点、关系、路径、来源、无图隐藏、移动端样式和 HTML 转义。

### Phase 5: 文档、回归与文章验证

#### 5.1 README

验证 GraphRAG、离线默认、模型 opt-in、资源上限、降级、隐私和 GitHub 示例表述。

#### 5.2 完整验证

运行完整 pytest、compileall、pip check、前端语法、context validator、INDEX 和差异检查。

#### 5.3 文章

渲染第 07 篇 DOCX，逐页检查标题、概念图、代码、GitHub 地址、表格、页眉页脚和溢出。

## 4 通过标准

- 正常、边界、失败、降级和循环终止路径都有行为断言。
- 测试不需要 `.env`、真实 API Key、网络、图数据库或真实模型。
- 实体、关系、路径、融合分数与排序在固定输入下确定。
- 报告不含向量、密钥、本地绝对路径、异常正文或未选中全文。
- 完整回归通过，代码、README、计划和文章使用相同边界表述。
