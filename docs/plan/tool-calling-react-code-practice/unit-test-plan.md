# Tool Calling、ReAct 与代码实践单元测试计划

> **版本**: 1.0
> **状态**: active
> **更新日期**: 2026-08-15

**关联 Checklist**: [unit-test-plan-checklist.md](./unit-test-plan-checklist.md)

## 1 测试目标

验证工具契约、练习生成、动态选择、受限执行、错误分类、评分提示、ReAct 终止和学习流程集成，所有测试使用本地固定输入，不调用真实模型或网络。

## Phase 1: Schema、生成器与注册表测试

- 验证字段长度、测试数量、未知字段、稳定练习 ID 和非代码主题。
- 验证生成/评价阶段、缺少练习和预算为零时的工具集合。

## Phase 2: 安全执行与 ReAct 测试

- 验证合法函数、import/open/dunder、无限循环、输出截断和临时路径清理。
- 验证不存在工具、非法参数、重复 Action、成功结果和预算耗尽终止。

## Phase 3: 分类、评分与提示测试

- 覆盖语法、策略、超时、资源、运行时、断言失败与全部通过。
- 验证分数只由测试统计产生，提示级别顺序稳定且不包含完整答案。

## Phase 4: Graph、State、Web 与兼容测试

- 验证代码主题生成结构化 interrupt，提交代码后报告进入 State 和 Web。
- 验证 SSE 事件、安全序列化、补救分支和成功总结。
- 验证非代码主题继续使用原 LCEL 练习与模型评价。

## Phase 5: 交付回归与文档测试

- 运行全部 pytest、Python 编译、前端语法、文档契约、上下文和 diff 检查。
- 验证 README 与第 08 篇文章的能力和安全边界与实现一致。

## 6 通过标准

- 聚焦测试覆盖正常、边界、错误与循环终止。
- 全量测试无需 `.env`、真实 API Key、外部模型或网络。
- 所有测试与静态检查通过，文档不存在 Header/INDEX 漂移。
