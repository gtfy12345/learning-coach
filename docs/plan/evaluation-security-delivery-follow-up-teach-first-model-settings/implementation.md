# 先教后测与本地模型设置实施计划

> **版本**: 1.0
> **状态**: completed
> **更新日期**: 2026-08-17

**关联 Checklist**: [implementation-checklist.md](./implementation-checklist.md)

## 1 目标

把新会话默认流程改为“有界基础教学 → 理解检查 → 按掌握情况进入迁移练习或针对性补讲”，保留显式先诊断模式；同时交付只在本机可用的模型设置页，支持内存 API 配置和 Codex/Claude 官方 CLI 登录，并保证密钥、旧会话和恢复协议安全。

## 2 背景

当前工作流固定先生成诊断题，用户希望默认先获得教学再检查掌握情况。当前模型只能通过启动参数、环境变量或终端认证配置，缺少可视化的本机设置入口。原评价计划已经 completed，本次以 follow-up 独立记录新的用户可见工作流和配置契约。

## 3 实施步骤

### Phase 1: 先教后测工作流

#### 1.1 定义学习模式、理解检查状态与兼容默认值

为 State、CLI、Web 请求与会话视图增加显式模式；新会话默认 `teach_first`，旧检查点缺字段时按 `diagnose_first`。

#### 1.2 以测试驱动实现基础教学、理解检查和分支路由

新增有界初始教学与理解检查评价节点；通过时直接进入迁移练习，未通过时把缺口交给现有教学子图，且不消耗正式评价次数。

#### 1.3 保持先诊断、补救上限、代码审批与恢复协议

验证 `diagnose_first` 与旧行为一致，两种模式最终仍使用 80 分通过线、最多两次评价以及现有代码执行审批。

### Phase 2: 内存模型配置与官方 CLI 认证

#### 2.1 实现脱敏的进程内 RuntimeModelConfigService 与测试门禁

支持现有 API Provider 与 CLI Provider，主模型和评价模型可独立选择；API 配置先以真实最小请求验证认证、模型和结构化输出，成功后生成 5 分钟有效、最多保留 8 个的一次性 `test_id`，只有该候选可被原子提升为当前运行时。失败时保留最后一个可用配置，API Key 不落盘不回显。

#### 2.2 绑定会话与模型运行时版本

新会话使用最新运行时，已存在会话在回答、流式恢复和时间旅行时继续使用创建时绑定的图与模型。

#### 2.3 增加回环限定的配置与认证 API

提供脱敏读取、API 测试、配置应用以及 Codex/Claude login/status/logout；敏感写请求要求回环客户端与同源 JSON，认证动作委托官方 CLI 并移出异步事件循环。

### Phase 3: Web 设置页与学习模式入口

#### 3.1 创建独立 `/settings` 页面

提供 API 与官方 CLI 两种卡片、Provider/模型选择、主/评价模型字段、密钥输入、登录状态和明确的内存保存说明。API 模式在测试成功前禁用“应用配置”，并提示测试会产生最小真实请求和可能费用。

#### 3.2 更新首页默认文案、模式选择和时间线

默认展示“先教学再检查”，允许切换“先诊断”；SSE/JSON 两条路径都提交并展示实际模式与中断类型。

#### 3.3 完成可访问性、错误态与秘密泄漏回归

覆盖键盘标签、加载态、非回环 403、API 错误脱敏、登录失败提示以及浏览器存储中无密钥。

### Phase 4: 文档与完整验证

#### 4.1 更新 README、`.env.example` 与公开边界

记录默认教学流程、CLI 参数、设置页、内存密钥语义和官方登录边界。

#### 4.2 完成全量测试与文档生命周期同步

运行 Python、前端语法、完整测试、context 校验、索引同步和 `git diff --check`，通过后将计划与 spec 标为 completed。

## 4 验收标准

- 默认新会话先显示教学内容，再等待理解检查回答；通过/未通过分支均可终止。
- 用户可显式选择旧先诊断模式，旧检查点继续按旧语义恢复。
- 设置页可在内存中配置现有 API Provider，响应、日志、State 和磁盘均不出现完整密钥。
- API 配置必须先通过真实最小连接测试；未测试、失败、过期或重复使用的候选不能应用。
- 设置页可委托 Codex/Claude 官方 CLI 登录、检查状态和退出。
- 配置切换只影响新会话，既有会话继续使用原模型运行时。
- 敏感接口拒绝非回环请求；全量测试与前端语法检查通过。

## 5 风险与应对

| 风险 | 应对措施 |
|------|----------|
| 先教后测造成重复讲解 | 理解检查通过直接进入迁移练习；只有未通过才进入补讲 |
| 旧检查点错误进入新节点 | 恢复状态缺模式时显式回退 `diagnose_first` |
| 运行时切换污染已有会话 | 会话绑定不可变的模型运行时版本 |
| API Key 泄漏 | 只进不出、私有内存对象、错误脱敏与负向测试 |
| 测试后配置被替换 | 服务端保存短期候选并以一次性 `test_id` 原子提升，不信任前端按钮状态 |
| 连接测试产生费用 | 页面在用户点击前明确提示；请求保持最小；自动化测试全部使用 fake |
| 配置端点被局域网调用 | 对敏感路由执行回环客户端校验 |
| 官方登录阻塞 Web | 在线程池执行并串行化同一 Provider 的认证动作 |
